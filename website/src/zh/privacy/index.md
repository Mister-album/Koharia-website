# 隐私政策

本政策说明 Koharia Android 应用和官方站点与隐私有关的基本做法。
Koharia 是连接你自行配置的 Komga 服务器的开源阅读器，并不提供媒体内容或独立的内容账户服务。

## 本地数据

为了提供阅读、同步和离线功能，应用可能会在你的设备上保存以下数据：

- 服务器地址、认证方式及连接相关设置。
- 当前账户可访问的媒体库信息和阅读偏好。
- 阅读进度、书签及其他阅读状态。
- 下载内容、缓存和你选择的存储位置。

具体内容取决于你启用的功能和已连接的 Komga 服务器。

## 网络连接

使用 Koharia 时，网络请求会发送到：

- 你自行添加的 Komga 服务器，用于认证、浏览媒体库、读取内容和同步阅读状态。
- GitHub，用于检查应用更新、打开 Release 页面或下载正式安装包。

Koharia 不会替你提供、托管或索引媒体内容。
你在 Komga 中的访问权限、服务器日志和数据处理方式由该服务器的运营者决定。

## 外部链接

官方网站和应用可能会链接至 GitHub、爱发电或其他第三方网站。
打开外部链接后，你应阅读相应服务的隐私政策；Koharia 无法控制这些服务如何处理数据。

## 你的控制权

你可以通过删除服务器配置、清理下载内容或清除应用数据来移除设备上的相应本地数据。
进行这些操作前，请确认是否需要保留阅读记录、下载内容和服务器连接设置。

请妥善保护 Komga 账号、密码和 API Key，并避免在公开 Issue、截图或日志中泄露它们。

## 政策更新

当应用功能或数据处理方式发生实质变化时，本页会相应更新。
建议在更新应用后定期查看本说明。

## 联系方式

如需报告隐私问题，请在 [Koharia Issues](https://github.com/Mister-album/Koharia/issues) 提交 Issue，并避免在公开内容中包含敏感信息。
