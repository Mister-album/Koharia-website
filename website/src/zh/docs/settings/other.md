# 其他设置

除书架、阅读器和下载设置外，Koharia 还提供用于管理应用整体行为的设置入口。

## 外观与语言

在外观相关设置中调整主题、界面显示和语言选项。
改变语言或显示方式后，请检查书架、阅读器和菜单中的显示是否符合预期。

## 数据与存储

数据相关设置用于查看或管理本地应用数据、存储和备份选项。
清理数据、迁移存储位置或恢复备份前，请确认你了解该操作是否会影响本地下载、服务器设置和阅读记录。

## 更新与安全

应用更新、安全保护和其他高级选项也位于设置中。
只应从[官方发布页](/zh/download/)获取 Koharia 安装包，并在变更安全设置前确认自己仍可访问应用和服务器。

## 寻求帮助

如果某项设置导致异常，可先恢复最近改变的选项，再参考[故障排查](/zh/docs/guides/troubleshooting/)。
