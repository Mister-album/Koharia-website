# 存储指南

Koharia 使用你选择的应用存储位置保存自动备份、Komga 离线下载和兼容性目录。
临时缓存和应用数据库则保存在应用的私有目录中。

你在本地库设置中关联的媒体目录使用各自独立的 Android 目录授权，不会被移动到这项应用存储位置中。

## 选择存储位置

你可以在首次启动引导中选择文件夹，也可以前往“设置 → 数据与存储 → 存储位置”重新选择。

::: tip 推荐做法

- 在内部存储的顶层新建一个专用的 `Koharia` 文件夹，例如“内部存储/Koharia”。
- 在系统文件选择器中授予整个 `Koharia` 文件夹的访问权限。
- 不要选择 `downloads`、`autobackup` 等子文件夹；Koharia 会在所选位置内自行创建它们。
- 避免直接选择存储设备根目录以及系统的“下载”“文档”等受限制目录。

:::

内部存储通常比 SD 卡更稳定、延迟更低。
使用 SD 卡时，请确保设备支持通过系统文件选择器持续访问该卡，并且不要在 Koharia 运行或下载期间移除它。

## 目录结构

Koharia 会在所选文件夹中维护以下结构：

```text
Koharia/
├─ autobackup/
├─ downloads/
│  ├─ <Komga 服务器名称>/
│  │  └─ <作品名称>/
│  │     └─ <章节或书籍文件、文件夹>
│  └─ Komga (Shared)/
└─ local/
```

- `autobackup` 保存应用自动生成的备份。
- `downloads` 保存漫画章节、EPUB、PDF 和其他可离线阅读的内容。
- `local` 是为本地来源兼容性保留的目录，普通 Komga 下载不会放在这里。

这里的 `local` 兼容性目录不同于你通过“使用本地文件夹”添加的本地库。
已配置的本地库会直接读取你授权的原目录。

作品、章节和服务器名称中的文件系统非法字符会被安全替换。
实际文件可能是单个 EPUB、PDF、压缩文件，也可能是包含图片的章节文件夹。
请以 Koharia 显示的下载状态为准，不要依赖固定的文件扩展名判断是否下载完成。

## Komga 下载目录模式

在服务器管理设置中，可以选择以下下载目录模式：

- **按服务器分开**：默认模式，每台 Komga 服务器使用自己的目录，便于区分来源和删除服务器数据。
- **共用目录**：多个 Komga 服务器共用 `Komga (Shared)`，适合它们指向同一套或高度重合的媒体库时减少重复离线文件。

请通过 Koharia 的服务器管理页面切换模式。
不要在文件管理器中手动合并服务器目录，否则下载索引可能无法对应正确的 Komga 内容。

## 本地库目录

本地库目录在创建本地库连接时单独选择，可位于内部存储或 Android 文件选择器支持的 SD 卡位置。
关联已有目录不会移动或删除文件；由 Koharia 创建书库时，则会在所选位置建立对应的 `Comics`、`Books` 与 `.koharia` 目录。

如果系统撤销权限或存储介质被移除，本地库将无法刷新或打开文件。
请重新授权同一目录，避免把本地库目录当作 Komga 下载目录手动迁移或重建索引。

## 下载与临时缓存的区别

已完成的下载位于所选存储位置的 `downloads` 目录，用于离线阅读。
封面、网络响应、元数据、阅读中的临时章节和 EPUB 解包内容属于缓存，保存在应用私有目录中。

清理缓存后，Koharia 可能需要重新请求封面、元数据或阅读内容，但不会以清理缓存为目的删除已完成的下载和备份。
清除 Android 系统设置中的“应用数据”或卸载应用会同时移除数据库、服务器配置和阅读状态，因此不能将其当作普通缓存清理方式。

## 更换或迁移存储位置

更换存储位置前，请暂停所有下载并创建一份最新备份。
仅在设置中选择新文件夹不会保证旧文件自动迁移。

如需保留现有离线内容：

1. 关闭 Koharia 的下载任务。
2. 将原存储位置中的完整目录结构复制到新的专用文件夹。
3. 在“设置 → 数据与存储 → 存储位置”选择新的根文件夹。
4. 前往“设置 → 高级 → 重建下载索引”，让 Koharia 重新扫描下载内容。
5. 确认离线内容和备份可用后，再删除旧文件。

不要把 `downloads` 文件夹本身选作存储位置。
正确做法是选择包含 `downloads`、`autobackup` 和 `local` 的上一级文件夹。

## Android 分区存储

Android 11 及更高版本使用分区存储限制应用访问整个设备。
Koharia 通过系统文件选择器获得对所选文件夹的长期读写权限，不需要也不应获得全部文件访问权限。

如果系统撤销权限、SD 卡被重新格式化或目录被其他应用移动，Koharia 将无法创建或识别下载。
此时请重新选择正确的存储根目录，然后重建下载索引。

## 常见问题

如果下载无法创建、内容突然显示为未下载或备份失败，请依次检查：

1. 存储设备是否仍然连接并可写入。
2. 剩余空间是否足够容纳下载和临时文件。
3. Koharia 是否仍拥有所选文件夹的访问权限。
4. 所选位置是否为专用根文件夹，而不是 `downloads` 子文件夹或系统受限目录。
5. 手动移动文件后是否执行了“重建下载索引”。

仍无法解决时，请阅读[故障排查](/zh/docs/guides/troubleshooting/)并在反馈中说明 Android 版本、存储介质和错误提示。

下载队列和网络相关选项请参阅[下载设置](/zh/docs/settings/downloads)。
