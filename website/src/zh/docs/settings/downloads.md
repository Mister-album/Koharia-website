# 下载

下载设置用于管理离线内容的存储位置、下载队列和网络使用方式。

## 存储位置

在开始大量下载前，先选择空间充足且稳定可用的存储位置。
请不要在下载进行中移除存储介质、撤销文件访问权限或清理应用数据。

有关目录选择、文件结构和迁移方式，请阅读[存储指南](/zh/docs/settings/storage)。

## 队列与网络

下载会进入队列并按当前网络条件执行。
对于较大的媒体库，建议在稳定的 Wi-Fi 环境中分批下载，以减轻移动网络、设备和服务器的负担。

## 出现问题时

下载失败时，先检查剩余存储空间、文件访问权限、网络连接和服务器是否可访问。
然后在 Komga 网页端确认同一账户能够打开该内容。

更多诊断步骤请阅读[故障排查](/zh/docs/guides/troubleshooting/)。
