# 漫画阅读器

漫画阅读器设置用于调整图片式漫画、图片目录、漫画压缩包、PDF 与 DjVu 的阅读体验。

## 阅读方式

根据内容和个人偏好选择合适的阅读模式。
阅读时也可以结合页面缩放和界面操作，获得更舒适的显示效果。

## 导航与操作

你可以调整页面导航、点击操作和双击动画等行为。
建议在阅读一部熟悉的作品时逐项尝试，确认操作方式符合习惯后再应用到日常阅读。

## 连接范围选项

部分阅读器行为可按连接分别设置。
当你连接多个 Komga 服务器或本地库，或各连接的内容类型差异较大时，这有助于保留各自合适的阅读体验。

EPUB、TXT 和实验性 Mobipocket / Kindle 文本请使用[书籍阅读器设置](/zh/docs/settings/book-reader)。
