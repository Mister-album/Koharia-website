# 书架

书架设置用于控制 Koharia 如何显示和更新已连接 Komga 服务器中的媒体库。

## 显示方式

你可以按自己的屏幕和阅读习惯调整书架布局、列数及章节信息的显示方式。
较小的屏幕通常适合较少列数；需要快速浏览更多封面时，可增加列数。

## 漫画与书籍分类

Koharia 可将当前服务器的媒体库归类为漫画或书籍。
这个分类决定你主要从哪个入口浏览内容，以及使用哪类阅读器体验。

如果服务器新增了媒体库，或你的 Komga 权限发生变化，请刷新媒体库后再检查分类。

## 更新与元数据

书架设置还包含媒体库更新和元数据刷新相关选项。
大量更新会占用网络、电量、设备存储和服务器资源，建议根据自己的网络、充电状态和服务器性能安排。
