# 书架

书架设置用于控制 Koharia 如何显示和更新当前 Komga 或本地库连接中的内容。

## 显示方式

你可以按自己的屏幕和阅读习惯调整书架布局、列数及章节信息的显示方式。
较小的屏幕通常适合较少列数；需要快速浏览更多封面时，可增加列数。

## 漫画与书籍分类

Koharia 可将当前 Komga 服务器的媒体库归类为漫画或书籍。
这个分类决定你主要从哪个入口浏览内容，以及使用哪类阅读器体验。

如果服务器新增了媒体库，或你的 Komga 权限发生变化，请刷新媒体库后再检查分类。

## 本地书库

创建本地库连接时，可以分别启用漫画与书籍书库、设置名称，并为每类内容选择系列库或单文件库。
配置完成后还可创建自定义书库，以及将目录和作品移动到兼容的书库中。

下拉刷新会重新扫描已授权目录。
移除目录只会清理 Koharia 的索引，不会删除原文件；组织方式和元数据保存位置则需要在创建时确认，完成后不能修改。

## 更新与元数据

书架设置还包含媒体库更新、筛选和元数据刷新相关选项。
Komga 的大量更新会占用网络与服务器资源，本地库扫描则会读取所授权的目录；请根据库规模、电量和存储性能安排。
