# 常见问题

## Koharia 是什么？

Koharia 是面向 Komga 与本地媒体库的第三方 Android 漫画和书籍阅读器。

它既可浏览当前 Komga 账户有权访问的内容，也可扫描你授权的设备目录，并提供对应的漫画、PDF 和可重排书籍阅读体验。

## Koharia 提供内容吗？

不提供。

Koharia 只显示你有权通过自己 Komga 服务器访问，或主动授权给应用扫描的本地内容。

## 使用本地库必须部署 Komga 吗？

不需要。

首次使用时选择“使用本地文件夹”，即可创建本地库连接。
Komga 服务器与本地库是彼此独立、可以同时存在的内容来源。

## 关联目录会移动或删除文件吗？

不会。

“添加已有目录”只会授予 Koharia 访问权限并建立索引；从本地库中移除目录也不会删除其中的原文件。
如果选择导入媒体、创建书库目录或将元数据写入 sidecar，则需要目录具备写入权限。

## 本地库支持哪些格式？

支持常见图片及图片目录、CBZ / ZIP / CBR / RAR / 7Z / TAR 等漫画压缩包，以及 EPUB、PDF、TXT、MOBI / PRC / AZW / AZW3 和 DjVu。
其中 Mobipocket / Kindle 文本支持为实验性，不支持 DRM、复杂布局与内嵌图片；DjVu 依赖设备 WebView 的 WebAssembly 能力。

## 为什么看不到某个媒体库？

请先确认该媒体库已在 Komga 中存在，并且当前账号拥有访问权限。
连接成功后，尝试刷新媒体库；若仍未显示，请检查服务器连接和账号权限。

## 阅读进度如何同步？

对于支持的内容，Koharia 会在设备可以连接服务器时将阅读进度同步到 Komga。
同步不代表离线内容会自动上传或下载；网络和服务器可用性仍会影响结果。
本地库的阅读位置、历史和书签保存在设备上，不会上传到 Komga。

## 下载失败怎么办？

对于 Komga 下载，请检查设备存储空间、文件访问权限、网络连接和服务器可用性。
也请在 Komga 网页端确认同一账号能够打开该内容。

更多步骤请阅读[故障排查](/zh/docs/guides/troubleshooting/)。

## 支持哪些 Android 版本？

Koharia 需要 Android 8.0 或更高版本。
