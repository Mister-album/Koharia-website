# 免责声明

Koharia 是由社区维护的第三方开源 Android 阅读器。
它用于连接你自行配置的 Komga 服务器，不隶属于 Komga，也不代表 Komga 提供任何服务或保证。

## 内容与授权

Koharia 不提供、托管、分发或索引媒体内容。
你应自行确认通过 Koharia 访问、下载或保存的内容及其使用方式符合所在地法律，以及内容权利人的授权要求。

## 服务器与账号安全

你负责自己的 Komga 服务器、网络暴露方式、账号权限和 API Key。
请勿在公开 Issue、截图或日志中提交服务器地址、密码、令牌或其他敏感信息。

## 软件状态

Koharia 按“现状”提供，不承诺适用于任何特定目的，也不保证服务始终可用或无错误。
在升级应用、清理数据或调整服务器前，请自行备份重要数据，并评估对阅读记录和下载内容的影响。

有关个人数据和网络请求的说明，请阅读[隐私说明](/zh/privacy/)。
