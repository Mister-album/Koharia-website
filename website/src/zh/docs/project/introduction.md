# Koharia 介绍

Koharia 是一款面向 Komga 服务器的开源 Android 阅读器。
它让你可以在 Android 设备上浏览、阅读和离线保存自己 Komga 服务器中有权访问的内容。

## Koharia 适合谁

Koharia 适合已经部署或可访问 Komga 服务器，并希望在 Android 上使用独立阅读体验的用户。

Koharia 不提供、托管或索引任何媒体内容。
你看到的内容、元数据和访问权限都由所连接的 Komga 服务器及其账户决定。

## 核心功能

- 连接一个或多个 Komga 服务器。
- 按漫画和书籍管理服务器中的媒体库。
- 阅读图片式漫画和 EPUB 书籍。
- 将阅读进度同步到 Komga。
- 下载或缓存内容，便于离线阅读。

## 系统要求

Koharia 需要 Android 8.0 或更高版本。

使用前请确保设备能够访问你的 Komga 服务器，并准备好服务器地址及登录凭据或 API Key。
