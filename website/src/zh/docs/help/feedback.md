# 交流反馈

Koharia 使用 GitHub 进行公开的缺陷反馈、功能建议和开发协作。

## 提交问题

请在 [Koharia Issues](https://github.com/Mister-album/Koharia/issues) 中提交问题。
为了便于定位，请附上：

- Koharia 版本和 Android 版本。
- 问题的复现步骤及实际结果。
- 问题发生时使用的网络类型和必要的设备信息。
- 已移除敏感信息的截图或日志。

## 提交建议

功能建议同样可通过 Issue 提交。
请说明希望解决的阅读场景，以及现有流程为何不能满足该需求。

## 保护敏感信息

不要公开服务器地址、用户名、密码、API Key、会话令牌、私人媒体库名称或含有这些信息的完整日志。
如发现隐私相关问题，请在 Issue 中仅提供最少的非敏感复现信息。

若希望支持维护工作，可前往[支持项目](/zh/support/)。
