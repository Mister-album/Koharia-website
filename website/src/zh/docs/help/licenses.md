# 开源许可证

Koharia 由开源软件及其社区协作构建。
请在使用、修改或再分发代码前阅读相应仓库中的完整许可证和 NOTICE 文件。

## Koharia Android 应用

Koharia Android 应用的源码、许可证和归属说明位于 [Mister-album/Koharia](https://github.com/Mister-album/Koharia)。
应用以仓库中声明的 Apache License 2.0 为准。

## Koharia 官方网站

本网站的源码、许可证和归属说明位于 [Mister-album/Koharia-website](https://github.com/Mister-album/Koharia-website)。
本网站以仓库中声明的 Mozilla Public License 2.0 为准。

## 第三方组件与来源致谢

各仓库会保留适用的第三方许可证、NOTICE 和来源归属信息。
这些文件是代码分发和贡献的重要组成部分，请勿在再分发时移除。
