# 故障排查

## 无法连接服务器

确认服务器地址、端口和登录信息正确。

请确认 Android 设备与 Komga 服务器处于可互相访问的网络中。

## 阅读或下载失败

先在 Komga 网页端确认相同账户可以打开对应内容。

然后检查设备存储空间和网络连接，并尝试重新打开该书籍。

## 仍未解决

在 [GitHub Issues](https://github.com/Mister-album/Koharia/issues) 中附上 Koharia 版本、Android 版本、问题步骤和已隐藏敏感信息的日志。
