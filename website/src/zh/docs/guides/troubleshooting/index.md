# 故障排查

## 无法连接服务器

确认服务器地址、端口和登录信息正确。

请确认 Android 设备与 Komga 服务器处于可互相访问的网络中。

## 阅读或下载失败

先在 Komga 网页端确认相同账户可以打开对应内容。

然后检查设备存储空间和网络连接，并尝试重新打开该书籍。

## 本地库没有显示文件

确认目录仍存在，并且 Koharia 仍拥有 Android 系统授予的访问权限，然后在本地库中下拉刷新。
检查文件格式是否受支持，以及当前书库选择的是系列库还是单文件库：系列库只会把根目录的直接子文件夹作为作品，单文件库则递归显示支持的文件和图片目录。

如果部分目录无法读取，Koharia 会保留已有索引；重新授权目录后再次刷新即可。

## 无法导入本地文件

导入需要至少一条已配置的本地库连接，以及一个内容类型匹配且可写的目标目录。
直接打开只支持单个文件；多个文件请使用导入流程。

## 仍未解决

在 [GitHub Issues](https://github.com/Mister-album/Koharia/issues) 中附上 Koharia 版本、Android 版本、问题步骤和已隐藏敏感信息的日志。
