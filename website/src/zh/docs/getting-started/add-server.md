# 添加 Komga 服务器

在 Koharia 的添加服务器界面，填写你的 Komga 服务器信息并完成验证。

## 准备信息

- **服务器地址**：使用设备可访问的完整地址，包括 `https://` 或 `http://` 和必要端口。
- **认证方式**：根据服务器配置，使用 API Key，或使用用户名和密码。
- **访问权限**：该 Komga 账户必须已获授需要浏览的媒体库权限。

## 添加步骤

1. 打开添加服务器或编辑服务器界面。
2. 输入服务器地址。
3. 选择 API Key，或用户名和密码认证，并填写相应信息。
4. 保存并等待 Koharia 验证连接。
5. 确认已加载该账户可访问的媒体库。

## 连接建议

- 手机上的地址必须能在手机当前网络中访问。
- 如果使用反向代理或 HTTPS，请先在浏览器中确认地址可正常打开。
- 请使用独立的 Komga 账户或权限范围，避免为移动端账户赋予不必要的管理权限。

连接失败时，请阅读[故障排查](/zh/docs/guides/troubleshooting/)。

如果内容保存在 Android 设备或 SD 卡上，请改为[添加本地库](/zh/docs/getting-started/add-local-library)。
