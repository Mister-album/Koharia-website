# 初始化设置

安装完成后，你可以添加 Komga 服务器、使用本地文件夹，或同时配置两种内容来源。

## 1. 确认系统要求

Koharia 需要 Android 8.0 或更高版本。

如果使用 Komga，请准备设备能够访问的服务器地址，以及用户名和密码或 API Key。
如果使用本地库，请确认文件已保存在 Android 系统文件选择器可以授权访问的位置。

## 2. 选择内容来源

首次打开应用时，根据内容所在位置选择：

- **添加服务器**：连接你自己的 Komga 服务器。
- **使用本地文件夹**：创建本地库连接，并关联已有目录或由 Koharia 创建书库目录。

这两种连接可以同时存在，也可以稍后从连接管理入口继续添加。

## 3. 完成对应配置

- 使用 Komga 时，请按照[添加 Komga 服务器](/zh/docs/getting-started/add-server)填写地址和认证信息。
- 使用设备文件时，请按照[添加本地库](/zh/docs/getting-started/add-local-library)选择书库组织方式、目录和元数据保存位置。

## 4. 检查媒体库

配置完成后，确认书架显示了预期内容。
Komga 只会显示当前账户有权访问的媒体库；本地库需要完成首次扫描，之后可通过下拉刷新重新索引文件。

## 5. 按需调整设置

开始阅读前，可以在设置中调整书架显示、阅读器和下载选项。
如果需要从 Komga 批量下载，建议先选择合适的下载存储位置，并在 Wi-Fi 或充电时进行操作。
