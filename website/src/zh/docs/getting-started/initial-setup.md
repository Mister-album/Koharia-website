# 初始化设置

安装完成后，按下面的顺序完成首次使用。

## 1. 确认使用条件

Koharia 需要 Android 8.0 或更高版本，并且设备必须能够访问你的 Komga 服务器。

请先准备服务器地址，以及用于登录的用户名和密码或 API Key。

## 2. 打开 Koharia

首次打开应用时，根据界面引导添加服务器。
如果此前已跳过，可以从应用中的服务器管理入口继续添加。

## 3. 检查媒体库

连接成功后，确认应用显示的是当前 Komga 账户有权访问的媒体库。
Koharia 可将服务器媒体库分别归类为漫画或书籍，方便进入对应阅读体验。

## 4. 按需调整设置

开始阅读前，可以在设置中调整书架显示、阅读器和下载选项。
建议先选择合适的下载存储位置，并在 Wi-Fi 或充电时进行大量下载。
