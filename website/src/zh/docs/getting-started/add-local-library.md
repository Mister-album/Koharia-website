# 添加本地库

本地库连接让 Koharia 直接扫描你授权的设备目录，不需要 Komga 服务器。
你可以关联正在使用的目录，也可以让 Koharia 创建漫画和书籍目录。

## 开始前

- 将文件放在 Android 系统文件选择器可以访问的位置；内部存储和受支持的 SD 卡均可使用。
- 关联已有目录只会授予 Koharia 扫描权限，不会移动或删除原文件。
- 如果希望导入文件或把元数据写回目录，请确保所选位置允许写入。

## 第 1 步：命名本地库

在首次使用界面选择“使用本地文件夹”，然后为这条本地库连接设置一个便于识别的名称。
你可以创建多条本地库连接，分别管理不同目录或组织方式。

## 第 2 步：选择书库与组织方式

启用漫画、书籍或两者，并为各自的默认书库命名。
每类书库都需要选择一种组织方式：

- **系列库**：根目录的直接子文件夹视为系列，其中的文件和图片目录视为章节或分册；书架先显示系列，点击后进入详情页。
- **单文件库**：递归扫描子目录，每个支持的文件或图片目录都直接作为独立作品显示，点击后立即阅读。

系列库适合已经按作品或系列整理的目录，单文件库适合散装书籍和没有固定层级的文件。
组织方式在本地库创建后不能修改；如需更换，请创建新的书库并关联对应目录。

## 第 3 步：添加目录

你可以选择以下任一方式：

- **添加已有目录**：选择现有的漫画或书籍目录，Koharia 会保留访问权限并建立本地索引，不会重排文件。
- **创建书库目录**：选择一个上级位置，Koharia 会根据已启用的内容类型创建 `Comics`、`Books` 和 `.koharia` 目录。

每个已启用的内容类型都需要至少一个对应目录，才能进入下一步。
移除本地库中的目录只会清理 Koharia 的索引，不会删除目录内的文件。

## 第 4 步：选择元数据保存位置

元数据保存方式决定你在 Koharia 中编辑的作品信息写到哪里：

- **应用数据库**：默认且最安全，不向书库目录写入文件。
- **原目录旁 sidecar**：编辑时在作品旁写入 `ComicInfo.xml` 或 `metadata.opf`。
- **统一元数据目录**：在本地库的 `.koharia/metadata` 目录中保存 JSON sidecar。

此选项在配置完成后不能修改，请确认后再点“完成”。

## 扫描与导入

配置完成后，Koharia 会索引目录并在书架显示作品。
新增、移动或修改文件后，可在本地库中下拉刷新；如果 Android 撤销了目录权限，需要重新授权。

你也可以从 Android 的“打开方式”或“分享”入口将受支持文件交给 Koharia：单个文件可使用临时副本直接阅读，也可导入到具备写入权限的本地目录。

## 支持的本地内容

| 类型 | 支持的扩展名或形式 |
| --- | --- |
| 漫画压缩包 | `CBZ`、`ZIP`、`CBR`、`RAR`、`7Z`、`CB7`、`TAR`、`CBT` |
| 图片与图片目录 | `JPG`、`JPEG`、`PNG`、`GIF`、`WEBP`、`AVIF`、`HEIF`、`HEIC`、`JXL` |
| 电子书与文档 | `EPUB`、`PDF`、`TXT`、`MOBI`、`PRC`、`AZW`、`AZW3`、`DJVU`、`DJV` |

MOBI、PRC、AZW 和 AZW3 为实验性文本阅读支持，不支持 DRM、复杂布局和内嵌图片。
DjVu 阅读依赖设备 Android WebView 的 WebAssembly 能力。
