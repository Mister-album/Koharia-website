# 参与贡献

Koharia 的源码、Issue 和发布都在 [GitHub](https://github.com/Mister-album/Koharia)。

提交问题时，请提供可复现步骤、Koharia 版本和 Android 版本，并隐藏服务器地址、令牌及其他敏感信息。

## 翻译

应用翻译由外部 Weblate 项目维护。

翻译入口将在公开后补充到此页面。

## 支持项目
