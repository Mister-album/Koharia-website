# 支持项目

Koharia 是由社区维护的开源项目。
如果它改善了你的阅读体验，欢迎通过爱发电支持后续维护和开发。

<a href="https://ifdian.net/a/album-Koharia" target="_blank" rel="noopener">前往爱发电支持 Koharia</a>

支持完全自愿，不会影响应用的功能、内容访问权限或 Issue 处理优先级。

也可以通过提交 Issue、改进文档、参与翻译或贡献代码来帮助项目。
请阅读[参与贡献](/zh/docs/contribute)。
