# About Koharia

Koharia is an open-source Android reader for Komga servers.
It lets you browse, read, and save for offline use the content that you are allowed to access on your own Komga server.

## Who Koharia is for

Koharia is for people who run, or can access, a Komga server and want a dedicated Android reading experience.

Koharia does not provide, host, or index media content.
The content, metadata, and access available in the app are determined by the connected Komga server and its account.

## Core features

- Connect one or more Komga servers.
- Organize server libraries as comics and books.
- Read image-based comics and EPUB books.
- Sync reading progress to Komga.
- Download or cache content for offline reading.

## System requirements

Koharia requires Android 8.0 or later.

Before getting started, make sure your device can reach your Komga server and have its address plus sign-in credentials or API key ready.
