It connects to Komga servers that you configure; it is not affiliated with, endorsed by, or a service of Komga.

## Server and account security

You are responsible for your Komga server, network exposure, account permissions, and API keys.
Do not include server addresses, passwords, tokens, or other sensitive data in public issues, screenshots, or logs.

Koharia is provided "as is", without a promise that it is fit for a particular purpose or always available and error-free.
