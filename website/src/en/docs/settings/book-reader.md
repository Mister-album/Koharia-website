# Book reader

The book reader is used for EPUB content from Komga.

## Typography and appearance

Adjust the font, text spacing, and reading background to make long reading sessions more comfortable.
If you read in different environments, review the display in both light and dark appearance.

## Progress and navigation

The book reader supports reading-progress sync, a table of contents, and bookmarks.
Progress sync requires the device to be able to reach the relevant Komga server.

## Cache

EPUB content can use local caching according to the app settings.
Caching can reduce repeated loading and dependence on the network, but it also uses device storage.

For saving content for offline use, also see [Download settings](/en/docs/settings/downloads).
