# Downloads

Download settings manage the storage location, queue, and network behavior for offline content.

## Storage location

Choose a stable location with sufficient free space before starting large downloads.
Do not remove the storage medium, revoke file access, or clear app data while downloads are in progress.

## Queue and network

Downloads enter a queue and run according to the current network conditions.
For large libraries, download in batches on a stable Wi-Fi connection to reduce the load on mobile data, the device, and the server.

## If something goes wrong

When a download fails, first check free storage, file permissions, network access, and whether the server is reachable.
Then confirm in Komga's web interface that the same account can open the content.

For more diagnostic steps, see [Troubleshooting](/en/docs/guides/troubleshooting/).
