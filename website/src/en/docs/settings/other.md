# Other settings

In addition to library, reader, and download settings, Koharia includes settings entries that manage the app's overall behavior.

## Appearance and language

Use appearance-related settings to adjust the theme, interface display, and language options.
After changing the language or display, check that the library, reader, and menus look as expected.

## Data and storage

Data-related settings let you review or manage local app data, storage, and backup options.
Before clearing data, moving storage, or restoring a backup, confirm whether the action affects local downloads, server settings, or reading records.

## Updates and security

App updates, security protection, and other advanced options are also available in Settings.
Only obtain Koharia installation packages from the [official releases page](/en/download/), and confirm that you can still access the app and server before changing security settings.

## Getting help

If a setting causes an issue, first revert the most recent change, then see [Troubleshooting](/en/docs/guides/troubleshooting/).
