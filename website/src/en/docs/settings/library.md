# Library

Library settings control how Koharia displays and updates content from the current Komga or local-library connection.

## Display

Adjust the library layout, column count, and chapter information display to suit your screen and reading habits.
Fewer columns usually work better on smaller screens, while more columns make it easier to scan many covers quickly.

## Comics and books classification

Koharia can classify the libraries of the current Komga server as comics or books.
The classification determines the primary place you browse the content and the reader experience used for it.

If the server adds libraries or your Komga permissions change, refresh the libraries before reviewing their classification.

## Local libraries

When creating a local-library connection, you can enable separate comics and books libraries, name them, and choose series-library or single-file organization for each content type.
After setup, you can also create custom libraries and move folders or items to a compatible library.

Pull to refresh rescans the authorized folders.
Removing a folder clears only Koharia's index and does not delete the original files; organization and metadata storage must be confirmed during creation and cannot be changed afterward.

## Updates and metadata

Library settings also include options related to updates, filters, and metadata refreshes.
Large Komga updates use network and server resources, while a local-library scan reads the authorized folders; schedule them according to library size, battery, and storage performance.
