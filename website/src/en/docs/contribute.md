# Contribute

Koharia source code, issues, and releases are hosted on [GitHub](https://github.com/Mister-album/Koharia).

When reporting a problem, include reproduction steps, the Koharia version, and the Android version. Remove server addresses, tokens, and other sensitive information.

## Translation

Application translations are maintained through an external Weblate project.

This page will link to the translation project once it is publicly available.

## Support the project

If Koharia improves your reading workflow, you can support maintenance through [Afdian](https://ifdian.net/a/album-Koharia).
