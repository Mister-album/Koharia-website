# Add a Komga server

Enter your Komga server details in Koharia's Add server screen and verify the connection.

## Prepare the details

- **Server address:** Use the complete address that your device can reach, including `https://` or `http://` and any required port.
- **Authentication:** Depending on the server configuration, use an API key or a username and password.
- **Access:** The Komga account must have permission to the libraries you want to browse.

## Steps

1. Open the Add server or Edit server screen.
2. Enter the server address.
3. Select API-key or username-and-password authentication, then enter the appropriate details.
4. Save and wait for Koharia to verify the connection.
5. Confirm that the libraries available to the account have loaded.

## Connection advice

- The address must be reachable from the phone's current network.
- If you use a reverse proxy or HTTPS, first verify that the address opens normally in a browser.
- Use a dedicated Komga account or permission scope instead of granting unnecessary administration permissions to a mobile account.

If the connection fails, see [Troubleshooting](/en/docs/guides/troubleshooting/).

If your content is stored on the Android device or an SD card, [add a local library](/en/docs/getting-started/add-local-library) instead.
