# Feedback

Koharia uses GitHub for public bug reports, feature requests, and development collaboration.

## Report an issue

Submit an issue through [Koharia Issues](https://github.com/Mister-album/Koharia/issues).
To make diagnosis easier, include:

- The Koharia and Android versions.
- Steps to reproduce and the actual result.
- The network type in use and relevant device details.
- Screenshots or logs with sensitive information removed.

## Suggest an improvement

Feature suggestions can be submitted as issues too.
Describe the reading scenario you want to solve and why the current flow does not meet the need.

## Protect sensitive information

Do not publicly share server addresses, usernames, passwords, API keys, session tokens, private library names, or unredacted logs containing them.
If you find a privacy-related issue, provide only the minimum non-sensitive information needed to reproduce it.

To help fund ongoing maintenance, visit [Support](/en/support/).
