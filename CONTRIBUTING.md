# Koharia Website Contributing Guide

Thank you for helping improve the Koharia website.

## Development setup

Install Node.js 22+ and pnpm 10+.

```powershell
cd website
pnpm install
pnpm dev
```

Run `pnpm test` before submitting a pull request.

## Content guidelines

- Maintain matching Chinese (`/zh/`) and English (`/en/`) content for public pages.
- Describe Koharia as a third-party Android reader for user-configured Komga servers.
- Do not publish server URLs, tokens, personal library data, or other private information in examples or screenshots.
- Use real Koharia screenshots for visual documentation and prefer WebP for large images.
